# Матрица протокольных режимов

| Возможность | WireGuard | AmneziaWG 3.0 | AmneziaWG 3.1 |
|---|---:|---:|---:|
| Базовый WireGuard handshake и transport через BoringTun | Подключено | Основа | Основа |
| H1-H4 | Нет | Конфигурационные типы | Конфигурационные типы |
| S1-S4 | Нет | Конфигурационные типы | Конфигурационные типы |
| Header protection | Нет | Только валидация требований | Только валидация требований |
| Content padding | Нет | Только тип конфигурации | Только тип конфигурации |
| Jc/Jmin/Jmax | Нет | Только тип конфигурации | Только тип конфигурации |
| I1-I5 | Нет | Не реализовано | Не реализовано |
| Рандомизируемые таймеры | Стандартные WG | Только тип конфигурации | Только тип конфигурации |
| RandomTrailers | Нет | Не поддерживается | Поле конфигурации |
| DisableCookies | Нет | Не поддерживается | Поле конфигурации |

**Важно:** "Подключено" означает использование базового BoringTun движка; AWG-совместимость не следует из этого автоматически. Эта таблица отражает фактический прогресс и не является заявлением о совместимости AWG.

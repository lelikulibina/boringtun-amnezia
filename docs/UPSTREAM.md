# Аудит upstream

## Cloudflare BoringTun

Для протокольного ядра используется опубликованный crate `boringtun = 0.7.1` с точным ограничением версии в Cargo.toml.

- Репозиторий: https://github.com/cloudflare/boringtun
- Версия crate: 0.7.1
- Лицензия: BSD-3-Clause
- Публичное ядро: `boringtun::noise::Tunn`.
- Базовые типы ключей экспортируются через `boringtun::x25519`.
- BoringTun предоставляет протокол WireGuard, но не сетевой/TUN стек.

README upstream предупреждает о реструктуризации и рекомендует использовать опубликованные crates.io пакеты, а не полагаться на master. Поэтому выбрана закреплённая версия crate, а не git-зависимость. Исходники BoringTun не копируются в этот репозиторий; лицензионные условия и notices upstream должны сохраняться при распространении.

## AmneziaWG Go

- Репозиторий: https://github.com/amnezia-vpn/amneziawg-go
- Текущий модуль: `github.com/amnezia-vpn/amneziawg-go/v3`.
- Файл `device/uapi.go` подтверждает обработку H1-H4, S1-S4, I1-I5, HeaderProtectionKey, ContentPaddingAddition, рандомизируемых таймеров, RandomTrailers и DisableCookies.
- При включённом HeaderProtectionKey реализация UAPI проверяет все четыре значения S1-S4: каждое должно быть не меньше 12 байт. Отсутствующее значение трактуется как ноль и не проходит проверку.
- RandomTrailers и DisableCookies присутствуют в актуальной ветке v3; их следует рассматривать как отдельные возможности 3.1, а не автоматически включать в 3.0.
- README описывает junk-пакеты Jc/Jmin/Jmax и сигнатурные пакеты I1-I5 с тегами статических/случайных байтов и timestamp.

Точная семантика преобразования каждого сообщения должна быть подтверждена по закреплённому commit и тест-векторам. Версия Go-модуля и commit SHA должны быть записаны в репозитории до завершения дифференциальных тестов.

## WireGuard Go

- Репозиторий: https://github.com/WireGuard/wireguard-go
- Используется как независимый поведенческий эталон для классического WireGuard.
- Нужны двусторонние тесты Rust/BoringTun ↔ wireguard-go.

## Текущее состояние

- BoringTun 0.7.1 подключён как протокольная зависимость.
- Публичный WireGuard API реэкспортирован.
- Добавлены интеграционные тесты полного handshake и шифрования/расшифрования IPv4 пакета между двумя экземплярами Tunn.

# Матрица протокольных режимов

| Возможность | WireGuard | AmneziaWG 3.0 | AmneziaWG 3.1 |
|---|---:|---:|---:|
| Базовый WireGuard handshake и transport через BoringTun | Подключено | Основа | Основа |
| H1-H4 | Нет | Конфигурационные типы + валидация пересечений | То же |
| S1-S4 | Нет | Конфигурационные типы + валидация HP | То же |
| Header protection | Нет | Только валидация требований | Только валидация требований |
| Content padding | Нет | Только тип конфигурации | Только тип конфигурации |
| Jc/Jmin/Jmax | Нет | Тип конфигурации + базовая валидация | То же |
| I1-I5 CPS parser/renderer | Нет | Реализован модуль шаблонов | То же |
| Реальная отправка I1-I5 и junk | Нет | Не реализовано | Не реализовано |
| Рандомизируемые таймеры | Стандартные WG | Только тип конфигурации | Только тип конфигурации |
| RandomTrailers | Нет | Не поддерживается | Только поле конфигурации |
| DisableCookies | Нет | Не поддерживается | Только поле конфигурации |
| Полное AWG packet transform / receive pipeline | Нет | Не реализовано | Не реализовано |

**Важно:** использование BoringTun означает наличие базового WG криптографического движка. Оно не означает, что AWG пакеты уже корректно преобразуются или принимаются.
